A single satirical sentence roasting the lawmakers who wrote a 400-page bill regulating AI, crypto, and the internet — then emailed that very bill to their own staff as `final_FINAL_v2.pdf.docx` and asked why nobody can open it. The program validates the line (one sentence, 1–320 characters) and writes it to `entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out-long-roast-lawmakers node main.ts
```
